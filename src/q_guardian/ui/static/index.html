About Q-Guardian

Q-Guardian is a hybrid quantum-classical framework for runtime security of autonomous AI agents. This console is a control plane over the existing detection pipeline:

  • Normalization — Unicode NFKC, hidden-character stripping, whitespace collapsing.
  • Validation — length, line, encoding and structural input limits.
  • Feature extraction — statistical, keyword and structural features.
  • Rule engine — built-in and custom detection rules.
  • Classical ML — Isolation Forest, Random Forest, XGBoost detectors (when models are loaded).
  • Quantum — local simulator and optional Qiskit backends for hybrid fusion.
  • Decision — ALLOW / WARN / REVIEW / BLOCK cascade with risk scoring.

API documentation is available at /docs and /redoc.
